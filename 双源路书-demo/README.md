# 莫友路书 · 别赶路，去感受路

> 一句需求，生成一份**每一站都能核实**的个性旅行路线。
> 解决的是：**来到一座陌生城市，不知道去哪、网上信息又过时**这个最日常的旅行焦虑。

## 一句话讲清这个产品

**给"第一次来这座城市、只知道景点名但不知道怎么走"的人，一份当下真实可执行、且按个人口味定制的旅行路线。**

市面上的旅行攻略/地图产品，普遍有四个坑：

| 痛点 | 传统产品 | 莫友路书 |
|---|---|---|
| **信息过时** | 收录的是几年前的网红店，可能早关门了 | 抓**最新**小红书笔记 + 高德实时 POI，过时的自动过滤 |
| **不知道去哪** | 罗列 50 个"值得去"，反而更迷茫 | 根据你说的一句需求（如"想要慢慢逛 + 喝杯咖啡"），**生成一条能走完的路** |
| **罗列难成行** | 清单式推荐，没法串成一天 | 按**区域聚类 + 时间 + 步行距离**排成 day 路线，防折返 |
| **千人一面** | 所有人都推同一份 | 按人群/偏好**个性化定制**（出片党、建筑迷、吃货、咖啡控都不同） |

## 为什么能解决 —— 我们的数据与 AI 架构

莫友路书是 **AI Native** 的，AI 是"大脑"，链接用户与真实世界：

- **实时数据（消息不滞后）**：爬取**小红书**等社交平台上的最新笔记与真实口碑，结合**高德 Web 服务**的真实 POI（评分 / 人均 / 营业时间 / 地址 / 坐标 / 照片）。社交数据更新快，商业数据准确——**双源互补**。
- **大模型处理海量数据**：小红书单点可能上千条笔记，人看不过来。大模型把海量碎片**去重、提权、归因**，留下"值得去"的，并说清为什么。
- **个化生成**：面对用户一句模糊需求，AI 先**主动反问引导**（节奏 / 预算 / 吃喝玩乐偏好），收敛成精确需求，再调用多源 Tools 规划，输出**按人群定制的路线**。
- **每一站都能核实**：每条推荐都带真实评分 + 真实营业时间 + 真实坐标 + 真实图，可查证，绝不编造。

## 功能亮点

- **AI 大脑「小莫」**：语音「嘿，小莫」或长按电源键唤醒；用**动态引导**逐步问清需求，实时拼出"需求句"，再生成路线。
- **真实卫星/街道地图**：用真实经纬度 Web Mercator 投影定位，画**规划好的行进路线**（起点/终点 / 分段 / 编号），可**拖动 + 缩放**（滚轮/双指/双击），POI 徽章反向缩放保持清晰。
- **📍 最佳摄影点标记**：路线中适于拍照的站点，在地图与卡片上标出 **📷 机位提示**（最佳机位更醒目），出片人群一眼可见。
- **多城市**：上海 / 北京 / 成都，各配文化色 + 城市文脉摄影 + 诗句（实时定位自动匹配城市）。
- **多主题**：城市漫步 / 建筑巡礼 / 咖啡地图 / 寻味街头 / 展览漫游 / 微醺夜晚 —— 吸引不同人群。
- **三视图**：`路线`（可交互地图）/ `行程`（卡片，拖拽重排 + 双源切换）/ `同路人`（社区互动：点赞/评论/回复/关注）。
- **竞品对比**：屏末「莫友 vs 主流」矩阵，讲清差异。

## 视觉品牌 —— 美术馆 · 画廊极简

一套统一的克制视觉系统（近白底 / 墨黑正文 / 单一朱砂红强调）：

| Token | 值 | 用途 |
|---|---|---|
| 纸感底 `--paper` | `#fafaf8` | 全屏近白美术馆底 |
| 主色 `--brand` | `#c03a2b` 朱砂红 | 唯一强调（按钮/标记/路线） |
| 辅助 `--accent` | `#6a8f5a` 苔绿 | 第二语义色 |
| 正文 `--ink` | `#1a1a1a` 墨黑 | 正文 |
| 分隔 `--line` | `#e6e6e2` | 发丝线 |
| 标题 | 衬线（Noto Serif SC） | 文艺 |

宠物「小莫」是只**猫**，可捏形（3 形态 × 5 配色），出现在主页、对话、AI 头像里。

## 数据说明

- POI 名 / 评分 / 人均 / 营业时间 / 地址 / 坐标 / 照片：**高德 Web 服务真实抓取**（可查证）。
- 小红书内容为**真实口碑样例**（演示"最新笔记 → 提权归因"流程），不冒充用户评分。
- 底图：Esri 卫星影像 / 高德街道瓦片（公开 URL，无需 key，国内可达）。
