# 莫友路书 · 每一站，都能核实

> 别赶路，去感受路。
> 一个以「真源」为核心的 AI 旅行产品原型 —— 输入一句需求，生成一份每一站都能核实的行程。

## 这是什么

一款面向城市漫步的 AI 旅行 Agent 原型。市面上的 AI 旅行产品最大的三个坑：**罗列清单难成行、行程不现实、信息过时/幻觉**。莫友路书用「**真实口碑 × 真实地点**」双源驱动解决：

- **真实数据**：所有 POI 的评分 / 人均 / 营业时间 / 地址 / 坐标 / 照片，全部来自高德 Web 服务真实抓取，可查证，绝不编造。
- **真实可执行**：按区域聚类防折返，营业中、未搬迁，当下真能去。
- **双源可溯源**：每条推荐都给真实评分 + 真实营业时间 + 真实图，可说清「为什么推荐它」。

## 视觉品牌 —— 纸上路书 · 胶片暖调

一套统一的品牌视觉系统（而非每屏杂乱）：

| Token | 值 | 用途 |
|---|---|---|
| 纸感底 `--paper` | `#f6f0e6` | 全屏米白纸感 + 细噪点纹理 |
| 主色 `--brand` | `#b5651d` 焦糖赭石 | 按钮 / 强调 / 品牌 |
| 辅助 `--accent` | `#6a8f5a` 苔绿 | 第二语义色 |
| 正文 `--ink` | `#3a2b1f` 暖深墨 | 非纯黑，更人文 |
| 标题 | 衬线（Noto Serif SC） | 文艺 |

## 功能

- **多城市**：上海 / 北京 / 成都，各配文化色 + 主界面 + 偏好词（点城市卡片整体联动）。
- **多主题**：城市漫步 / 建筑巡礼 / 咖啡地图 / 寻味街头 / 展览漫游 / 微醺夜晚 —— 吸引不同人群。
- **手绘路书图**：米白纸底 + 品牌色路线 + 墨色序号点 + 衬线地名；点序号 → 定位到对应行程卡片并高亮。稳定渲染，永不空白。
- **三视图**：`路线`（手绘路书图）/ `行程`（卡片，含拖拽重排 + 双源切换）/ `同路人`（社区）。
- **同路人 · 社区**：锚定本趟真实 POI 的社区 feed，支持点赞 / 评论 / 回复 / 关注。
- **拖拽重排**：同行内可拖，跨天隔离。
- **竞品对比**：屏末「莫友 vs 主流同行」矩阵，讲清差异。

## 数据说明

- POI 名 / 评分 / 人均 / 营业时间 / 地址 / 坐标 / 照片：高德 Web 服务真实抓取。
- 「同路人」社区内容为**示例社区**，用于演示社交互动；不冒充真实用户评分。

## 运行

双击 `index.html` 或用本地服务器：

```bash
python3 -m http.server 8899
# http://localhost:8899
```
